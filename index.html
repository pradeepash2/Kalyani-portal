How to Publish Kalyani Coaching Classes Free

Go live in less than 5 minutes on the web without any cost

1 Method 1: Netlify Drop (Takes 60 seconds - No coding required)

  1. Save this file on your computer as index.html inside a new folder named kalyani-portal.
  2. Visit app.netlify.com/drop in your browser.
  3. Drag & drop the entire kalyani-portal folder into the designated box.
  4. Netlify will give you an instant live URL like kalyani-classes.netlify.app that anyone can open on phone or PC!

2 Method 2: Vercel Free Hosting

  1. Create a free account on vercel.com.
  2. Push this file to a GitHub repository or use Vercel CLI (vercel deploy).
  3. Connect your own custom domain (e.g. kalyanicoaching.in or .com) at zero hosting fees.

3 Method 3: GitHub Pages

  1. Create a free GitHub repository (e.g., kalyani-coaching).
  2. Upload this index.html to the root branch (main).
  3. Go to Settings → Pages → Source and pick main branch / root.
  4. Your site goes live at https://yourusername.github.io/kalyani-coaching.
Tip for 2,000+ Students Cloud Sync:

This application already saves everything in browser storage. When you want automatic cross-device synchronization between teacher phones and student laptops, connect a free Supabase (PostgreSQL) project using their JavaScript client.
